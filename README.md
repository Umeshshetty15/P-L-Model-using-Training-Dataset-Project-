# P-L-Model-using-Training-Dataset-Project-
Built a 3-year FY24–FY26 P&amp;L model in Excel using 150+ GL accounts and SUMIF-based automation. Automated YoY variance and profitability KPI analysis, identifying a 49% EBITDA decline in FY25 and 25% recovery in FY26. Created charts to visualize financial trends and performance drivers.
